# VASTRA VISION

Recognizing the design beyond the color.

VASTRA VISION is a React, TypeScript, and Tailwind CSS frontend prototype for an AI-powered Indian saree/fabric design recognition system.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Dataset

Place actual textile images in:

- `src/assets/dataset/Banarasi`
- `src/assets/dataset/Bandhani`
- `src/assets/dataset/Ikat`
- `src/assets/dataset/Pichwai`

The frontend auto-discovers supported local image files. Frontend prototype - real ML inference is not connected.
